Privacy,
kept deliberately small.

Color by Tej SolPro is designed to perform deterministic color calculations without user accounts or a stored project history.

This policy covers the public website and the Color by Tej SolPro plugin for ChatGPT and Codex.

Data processed

The website does not require an account. When you invoke the plugin, it processes the hexadecimal color values and options needed to answer your request. Hosting infrastructure may also process ordinary connection information such as IP address, request time, user agent, and error status.

Do not submit passwords, authentication secrets, health information, payment information, government identifiers, or other personal data. The plugin does not need them.

How it is used

Color inputs are used only to calculate semantic tokens, CSS, provenance, and WCAG contrast evidence. Limited technical metadata may be used to keep the service secure, diagnose failures, prevent abuse, and measure reliability.

Sharing and service providers

Your request is handled through the ChatGPT or Codex product you use and the infrastructure hosting the MCP endpoint. Tej SolPro does not sell plugin data, use it for advertising, or share it with data brokers.

Retention

The plugin is designed not to create a database of color inputs or conversation content. Production application logs will exclude tool arguments and results. Infrastructure-level operational metadata may be retained for up to 30 days for security and reliability, then deleted or aggregated.

Your choices and contact

You can stop processing by not invoking or by uninstalling the plugin. To ask a privacy question or report a concern, use the public GitHub issue tracker ↗ and avoid including private information. See Support for other project links.

Changes

Material changes will be dated on this page and recorded in the public repository.
