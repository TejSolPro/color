01 / Why agents need a system

AI can build the screen.
Color gives it rules.

Prompts describe a mood, but agents need structured constraints they can reuse. Color assigns jobs to colors, verifies exact foreground and background pairs, records transformations, and produces decisions an agent—or a human—can inspect.

02 / Available in 0.1.0

From one color to implementation.

  1. 01Preserve

    Keep the requested brand and canvas values locked after hex normalization.

  2. 02Derive

    Generate eleven semantic roles using documented deterministic transformations.

  3. 03Prove

    Audit nine exact text, state, boundary, and focus pairs against WCAG 2.2.

  4. 04Explain

    Return schema, algorithm, decisions, and provenance with every result.

  5. 05Export

    Deliver machine-readable JSON or implementation-ready CSS.

03 / The standard

Explain every decision.

Deterministic

Identical structured inputs and data versions produce identical results.

Accessible

Claims attach to exact intended pairs—not to a palette-wide badge.

Traceable

Every source, conversion, and generated color retains its history.

Portable

The core remains independent of models, vendors, plugins, and frameworks.
