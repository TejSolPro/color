The core is deliberately small today. Its first reliable primitive calculates WCAG contrast without network access or model dependencies.

Install

Current status

Color is in foundation development and has not yet been published to a package registry. Clone the repository to inspect or contribute to the TypeScript workspace.

git clone https://github.com/TejSolPro/color.git
cd color
pnpm install
pnpm test

Core API

Contrast primitives

The core exposes deterministic utilities for parsing hexadecimal colors, calculating relative luminance, producing contrast ratios, and evaluating common WCAG thresholds.

import { contrastRatio, auditPair } from "@tejsolpro/color";

const ratio = contrastRatio("#1C1A17", "#F3EFE7");
const result = auditPair("#1C1A17", "#F3EFE7");

// result: { ratio, aaNormal, aaLarge, aaaNormal, aaaLarge }

API names may evolve before the first tagged release. Pin a commit if you experiment with the project today.
