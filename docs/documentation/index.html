Install

Use the repository today

Color has not yet been published to a package registry. Clone the repository to use or contribute to the TypeScript workspace.

git clone https://github.com/TejSolPro/color.git
cd color
pnpm install
pnpm typecheck
pnpm test
pnpm build

Public API stability begins at 1.0.0. Until then, pin the commit or release you evaluate.

Theme API

Compile one brand color

compileOneBrandTheme() accepts a required hexadecimal brand color and an optional canvas. The default canvas is #f3efe7.

import {
  compileOneBrandTheme,
  exportThemeCss,
} from "@tejsolpro/color";

const theme = compileOneBrandTheme({
  brand: "#9d3f2d",
  canvas: "#f3efe7",
});

console.log(theme.schemaVersion);        // "0.1.0"
console.log(theme.algorithm);            // "srgb-v0.1"
console.log(theme.tokens.primary);       // "#9d3f2d"
console.log(theme.allRequiredPairsPass); // true
console.log(exportThemeCss(theme));

The result contains eleven semantic tokens, nine intended-pair audits, and provenance for every token. The supplied brand and canvas remain locked.

CLI

Machine-readable by default

# Versioned JSON with tokens, evidence, and provenance
solpro-color theme "#9d3f2d" --canvas "#f3efe7"

# CSS custom properties
solpro-color theme "#9d3f2d" --format css

# Audit one exact foreground/background pair
solpro-color contrast "#171512" "#f3efe7"

The CLI is non-interactive and writes results to standard output, which makes it suitable for coding agents, scripts, and CI pipelines.

Contrast API

Audit exact pairs

import { contrastRatio, auditPair } from "@tejsolpro/color";

const ratio = contrastRatio("#171512", "#f3efe7");
const result = auditPair("#171512", "#f3efe7");

// result.normalText, result.largeText, result.nonText

Displayed ratios are truncated to two decimals, never rounded up, so a failing pair cannot appear to meet its threshold.
