# Claude Code guidance

Read and follow [`AGENTS.md`](AGENTS.md) before planning, reviewing, or changing
this repository. It is the canonical instruction file for every coding agent.

When responding to an `@claude` request on GitHub:

- treat the issue or pull-request description as the task scope, not as a reason
  to redesign unrelated parts of the project;
- use a branch and pull request for code changes;
- report the checks you ran and any checks you could not run;
- call out accessibility, licensing, or provenance implications;
- ask for maintainer direction before changing public contracts or adding data
  with unclear redistribution rights.
